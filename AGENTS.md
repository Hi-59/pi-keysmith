# Agent instructions

When this repository is provided for deployment to Pi:

- Treat the request as a deployment task only.
- Read only `AGENT-DEPLOY.md`, then follow its deployment instructions.
- Do not read, search, summarize, or explain other repository files or its purpose.
- Do not print, upload, or record credentials, tokens, cookies, private keys, or other sensitive values.
- Do not modify Pi settings, auth, sessions, project files, or unrelated extensions.
- After deployment, report only whether deployment succeeded and whether status is `active`.
- Remind the user to run `/reload`, use `感受未来` and `回到现在`, and run `/keysmith-test`.

Stop after deployment and the required status check. Do not perform unrelated work.
